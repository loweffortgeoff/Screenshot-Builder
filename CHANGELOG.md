# Changelog

## Unreleased
- Chapter 3 (branch `feature/chapter-3`, not merged): caption compositions (Stacked, Side by side, Big number with a stat, Overlay with a frosted band, Text only) with a per-shot override; project format version 4.
- Mac: display captures fill the MacBook screen with a crop-position slider and a Fit choice (Auto, Fill screen, Window); a Window only frame; a MacBook redrawn from a fresh bezel measurement (deck, lit notch, specular lip, feet, contact shadow).
- iPad: devices fill at least about 70% of the width in portrait; Duo is grounded; glows are stronger on mesh themes.
- Editor: the preview fills the pane with zoom controls (⌘−, ⌘0, ⌘1, ⌘=, pinch); Set view (⌘2) shows and reorders the whole set; double-click a headline, subtitle, badge, or stat to edit it on the canvas; drag the Zoom ring and card. The list sidebar is gone.
- Caption tab: "Ag" font tiles and weight segments that offer only the family's real faces. Device tab: the device name with a frame diagram, labelled finish swatches, and a Placement group.
- Zoom: the crop snaps to whole blocks of rows, magnifies 1.6–2.2×, and uses a spotlight marker with a lens connector instead of a second white box.
- UI council for chapter 3: medians 7.3, 7.4, 7.4 over three rounds (pass bar 8.0 not met).
- Added optional per-shot badges above the headline.
- Added per-shot arrangements (Tilt, Hero, Duo, Zoom callout with an Auto region and row-snapped crop), Vary layouts and Make uniform, a capture-fit warning, retuned theme contrast, and a clean bleed edge.
- UI council median rose from 3.8 (v1) to 7.5 across both chapters; Geoff accepted 7.5 on 2026-11-13.
- Added layout templates with bleed variants, a whole-set filmstrip, composed sidebar thumbnails, a sectioned inspector with visual pickers, a grouped size menu, and a prominent Export button.
- Added eight macOS font families, weight, size, and alignment controls, accent words with *asterisks*, balanced line breaks, and a set-wide caption band that keeps headlines aligned.
- Added measured device frames for iPhone, iPad, and MacBook with Dynamic Island, camera notch, side buttons, display-corner clipping, landscape rotation, and sampled finishes.
- Added 14 curated themes, gradient, radial, and mesh backgrounds, an accent color, a soft screenshot shadow, and backgrounds that flow across the whole set.
- Built the approved native Mac screenshot builder with shared styling, fixed caption bands, project saving, layout validation, and batch PNG export.
- Tightened caption space and canvas margins so short captions leave more room for the screenshot.
