# Screenshot Builder

A native Mac app to frame screenshots, write captions, and export an App Store set.

## Run

Requires macOS 14 or later and Xcode command line tools. Run `./scripts/build-app.sh`, then open `build/Screenshot Builder.app`. Open `Package.swift` in Xcode to edit.

## Review harness

`SB_SAMPLES=<folder of 01.png…> SB_OUT=<folder> swift test --filter SampleRenderTests` renders a sample set, a contact sheet, and a project file. `SB_PROJECT=<file.shotset>` renders a saved project as it is, in place of `SB_SAMPLES`. Optional: `SB_REGION`, `SB_MARKER`, `SB_LENS` (Zoom options, applied to every shot, by raw value such as `Top`, `Outline`, `Line`), `SB_THEME`, `SB_LAYOUT`, `SB_PRESET`, `SB_FINISH`, `SB_FRAME` (`windowOnly` for the bare Mac window), `SB_MACFIT` (`auto`, `fill`, `window`) and `SB_CROP` (0 to 1, which part of a cropped Mac capture shows; both applied to every shot), `SB_SPAN=1`, `SB_LANDSCAPE=1`, `SB_ALIGN`, `SB_FONT`, `SB_ARRANGE` (`vary` runs Vary layouts, compositions included, or an arrangement name), `SB_COMPOSITION` (`sideBySide`, `bigNumber`, `overlay`, `textOnly`, or a raw value, set for the whole set), `SB_CAPTIONS` (a file of `headline|subtitle` lines), `SB_BADGES` (for example `1:New,3:Insights`), `SB_STAT` (the Big number stat, for example `1:2×,3:10k`, or one value for every shot). `scripts/capture-window.sh <project> <png>` opens a project in the built app and captures its window (needs Screen Recording permission).

## Workflow

Import PNG or JPEG images, select a size, write captions, and export. The preview fills its pane; zoom with the toolbar, ⌘−, ⌘0 (Fit), ⌘1 (100%), ⌘=, or a pinch. The filmstrip under the preview shows the whole set as it will export; select a shot there, or right-click it to move, replace, or remove it. Set view (⌘2) shows every shot large: click one to open it, or drag to reorder. Double-click a headline, subtitle, badge, or stat on the canvas to edit it in place; on a Zoom shot, drag the ring or the card. The inspector has three tabs: Caption (headline, subtitle, badge, stat, font tiles, real weights, size, alignment, colors), Style (layout template, composition, Vary layouts, the selected shot's composition and arrangement, Mac fit, theme, background), and Device (export summary, device and frame, finish, placement). Compositions are Stacked, Side by side, Big number, Overlay, and Text only; each shot can follow the set or choose its own. On the Mac preset, display captures fill the screen (a crop slider picks the part that shows), and Window only draws a bare window. Output size and orientation are in the toolbar. Each shot can use its own arrangement: Tilt, Hero, Duo (a second screen from another shot), or Zoom (a magnified card of part of the screen). "Vary layouts" assigns a curated mix; "Make uniform" resets it. Use the Highlight menu beside the headline to color words with the theme accent; typed *asterisks* also work. Overflow warnings block export; low-resolution warnings flag possible softness. Styling applies to the full set. Save a `.shotset` project through the File menu; source images travel with it.

Size presets follow [Apple screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/) checked on 2026-09-07. Exports use opaque RGB PNGs. Device frames are drawn in code from measurements of Apple Design Resources bezels (iPhone 18 Pro and Pro Max, iPad Pro M5, MacBook Air M5), checked on 2026-11-13. No Apple images are bundled. The 5.5-inch home-button frame is an estimate. A device frame clips the capture only to the rounded display corners. On the MacBook, a full-display capture fills the screen, and a window capture floats on a wallpaper.
