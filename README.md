# Matte

A native Mac app to frame screenshots, write captions, and export an App Store set.

## Run

Requires macOS 14 or later and Xcode command line tools. Run `./scripts/build-app.sh`, then open `build/Matte.app`. Open `Package.swift` in Xcode to edit.

## Review harness

`SB_SAMPLES=<folder of 01.png…> SB_OUT=<folder> swift test --filter SampleRenderTests` renders a sample set, a contact sheet, and a project file. `SB_PROJECT=<file.shotset>` renders a saved project as it is, in place of `SB_SAMPLES`. Optional: `SB_REGION`, `SB_MARKER`, `SB_LENS` (Zoom options, applied to every shot, by raw value such as `Top`, `Outline`, `Line`), `SB_THEME`, `SB_LAYOUT`, `SB_PRESET`, `SB_FINISH`, `SB_FRAME` (`windowOnly` for the bare Mac window), `SB_MACFIT` (`auto`, `fill`, `window`) and `SB_CROP` (0 to 1, which part of a cropped Mac capture shows; both applied to every shot), `SB_SPAN=1`, `SB_LANDSCAPE=1`, `SB_ALIGN`, `SB_FONT`, `SB_ARRANGE` (`vary` runs Vary layouts, compositions included, or an arrangement name), `SB_COMPOSITION` (`sideBySide`, `bigNumber`, `overlay`, `textOnly`, or a raw value, set for the whole set), `SB_CAPTIONS` (a file of `headline|subtitle` lines), `SB_BADGES` (for example `1:New,3:Insights`), `SB_STAT` (the Big number stat, for example `1:2×,3:10k`, or one value for every shot). Decorations, which also apply to `SB_PROJECT`: `SB_EYEBROW` (`appName`, `section`, `numbered`, or `off`), `SB_APPNAME`, `SB_SECTIONS` (for example `1:Your list,3:Spending`), `SB_RULE=1`, `SB_SHAPES=1`, `SB_MONO=1`; backdrops: `SB_BACKDROP` (`orb`, `bokeh`, `arcs`, `rays`, `none`), `SB_HUESHIFT=1`; `SB_LOOK` (a starter look by name, applied before the decoration and backdrop knobs). `scripts/capture-window.sh <project> <png> [app arguments]` opens a project in the built app and captures its window (needs Screen Recording permission); `-SBInspectorTab Caption` (or `Style`, `Device`) and `-SBCanvasMode set` open that view without clicks. `scripts/compare-renders.sh <revA> <revB>` renders the chapter 2 slot projects at two revisions (`.` is this checkout) and compares every export pixel by pixel.

## Workflow

Import PNG or JPEG images, select a size, write captions, and export. The preview fills its pane; zoom with the toolbar, ⌘−, ⌘0 (Fit), ⌘1 (100%), ⌘=, or a pinch. The filmstrip under the preview shows the whole set as it will export; select a shot there, or right-click it to move, replace, or remove it. Set view (⌘2) shows every shot large: click one to open it, or drag to reorder. Double-click a headline, subtitle, badge, or stat on the canvas to edit it in place; on a Zoom shot, drag the ring or the card. The inspector has three tabs: Caption (headline, subtitle, badge, stat, font tiles, real weights, size, alignment, colors), Style (layout template, composition, Vary layouts, the selected shot's composition and arrangement, Mac fit, theme, background), and Device (export summary, device and frame, finish, placement). Compositions are Stacked, Side by side, Big number, Overlay, and Text only; each shot can follow the set or choose its own. On a portrait iPhone, Side by side is named Lead: a left caption over a large phone that runs off the bottom edge. The Style tab opens with six starter looks (Orb, Bokeh, Editorial, Scoreboard, Rays, Calm): one click sets the theme, type, layout, backdrop, and decorations for the whole set, keeping captions, arrangements, and the device; Undo reverts it. Decorations (Caption tab, for the whole set): an eyebrow label above the headline (App name, a Section per shot, or Numbered, which follows the set order), an accent rule at the start of the eyebrow line, and two small accent shapes in a top corner, which hide when the caption or device needs the space. Double-click an eyebrow on the canvas to edit it. Advanced background (Style tab, under the themes) adds one backdrop layer behind the device (Orb, Bokeh, Arcs, or Rays) and an optional hue shift that turns each shot's background a step further across the set; it is off while the background flows across the set. On the Mac preset, display captures fill the screen (a crop slider picks the part that shows), and Window only draws a bare window. Output size and orientation are in the toolbar. iPhone Duo (2007 × 2853, portrait) draws each shot open or closed, in portrait or landscape, from its capture size: an outer-screen capture (1398 × 2034) shows the folded Duo with its camera, and an inner-screen capture shows it unfolded. Each shot can use its own arrangement: Tilt, Hero, Duo (a second screen from another shot), or Zoom (a magnified card of part of the screen). "Vary layouts" assigns a curated mix; "Make uniform" resets it. Use the Highlight menu beside the headline to color words with the theme accent; typed *asterisks* also work. Overflow warnings block export; low-resolution warnings flag possible softness. Styling applies to the full set. Save a `.shotset` project through the File menu; source images travel with it.

Size presets follow [Apple screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/) checked on 2026-09-07. Exports use opaque RGB PNGs. Device frames are drawn in code from measurements of Apple Design Resources bezels (iPhone 18 Pro and Pro Max, iPad Pro M5, MacBook Air M5), checked on 2026-11-13. No Apple images are bundled. The 5.5-inch home-button frame is an estimate. A device frame clips the capture only to the rounded display corners. On the MacBook, a full-display capture fills the screen, and a window capture floats on a wallpaper.
